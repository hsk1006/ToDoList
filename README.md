# ToDo List Web Application

## Overview
A web-based task management application that allows users to manage daily tasks efficiently. Users can add, delete, and mark tasks as completed with real-time UI updates.

## Technologies
- HTML
- CSS
- JavaScript
- LocalStorage

## Features
- Add new tasks dynamically
- Mark tasks as completed or uncompleted
- Delete tasks
- Persistent storage using browser LocalStorage
- Responsive and user-friendly interface

## Key Learnings
- DOM manipulation using JavaScript
- Event handling for dynamic user interaction
- Data persistence using LocalStorage
- Building and deploying a complete web application
